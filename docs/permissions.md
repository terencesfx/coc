# 权限设计

后端是权限判断的唯一可信来源。前端隐藏按钮只改善体验，不构成权限保护。

## 1. 人物卡权限

| 操作 | 所有者 | 挂靠团本 KP | 其他可见用户 | 无可见权限用户 |
|---|---:|---:|---:|---:|
| 查看当前人物卡 | 是 | 是 | 是 | 否 |
| 编辑当前人物卡 | 是 | 是 | 否 | 否 |
| 查看完整历史 | 是 | 是 | 是 | 否 |
| 比较历史版本 | 是 | 是 | 是 | 否 |
| 恢复历史版本 | 是 | 是 | 否 | 否 |
| 挂靠自己的卡 | 是 | 否 | 否 | 否 |
| 解除自己的挂靠 | 是 | 团本 KP 可管理 | 否 | 否 |
| 归档人物卡 | 是 | 否 | 否 | 否 |

只要人物卡挂靠到某个用户担任 KP 的团本，该 KP 就拥有编辑权。解除所有相关挂靠后，KP 立即失去编辑权，但其既有修改历史永久保留。

人物卡当前为公开调查员或公开 NPC 时，其他已登录用户可以只读查看。未挂靠的私人档案和隐藏 NPC 不可见。

## 2. 团本权限

| 操作 | 团本 KP | 其他用户 |
|---|---:|---:|
| 查看团本概要 | 是 | 是 |
| 编辑团本资料 | 是 | 否 |
| 查看公开内容块 | 是 | 是 |
| 查看 KP 内容块 | 是 | 否 |
| 管理调查员挂靠 | 是 | 仅管理自己的申请/挂靠 |
| 创建和管理 NPC | 是 | 否 |
| 更改 NPC 可见性 | 是 | 否 |
| 查看团本公开骰 | 是 | 是 |
| 查看 KP 暗骰 | 是 | 否 |
| 配置 QQ 通知 | 是 | 否 |

## 3. 管理员权限

管理员可以创建、停用账号和重置密码。管理员不因系统身份自动获得团本私密内容和人物卡编辑权，避免日常使用中混淆系统维护与游戏角色。

如未来需要故障排查，可增加显式、带审计记录的管理员临时访问机制，不在首版默认开放。

## 4. 历史与删除

- 历史版本不可编辑或删除；
- 恢复旧版本也是一次新的、可追踪的修改；
- 人物卡、团本和账号采用软删除或归档；
- 禁止通过普通界面清除人物卡历史；
- 所有写操作记录操作者和服务端时间。
